# NIL33 Genome v1.0 — Research Paper

A DOI-ready research paper documenting the NIL33 deterministic underwriting engine
with cryptographic model identity, genome-stamped capital lifecycle objects,
and portfolio-level evolutionary analytics.

## Prerequisites

- **Pandoc** ≥ 2.19 — <https://pandoc.org/installing.html>
- **LaTeX** (MiKTeX or TeX Live) with `xelatex` — <https://miktex.org/>
- **Node.js** ≥ 18 — for artifact export
- **PowerShell** ≥ 5.1

## Build Commands

```powershell
# 1. Generate research artifacts (snapshots, replay records, synthetic data)
pwsh research/nil33-genome-paper/scripts/export-artifacts.ps1

# 2. Build the PDF
pwsh research/nil33-genome-paper/scripts/build.ps1
```

Output: `research/nil33-genome-paper/dist/NIL33_Genome_v1_0.pdf`
